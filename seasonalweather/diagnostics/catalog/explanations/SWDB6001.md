# SWDB6001 — Database access denied

## Meaning

PostgreSQL rejected authentication or denied required privileges.

## Trigger

An archive operation received a confirmed database access denial.

## Correction or recovery

Verify the database role, secret provisioning, server access policy, and schema grants. Do not share credentials or connection strings.

## Operational effect

The affected archive operation cannot proceed. Local broadcasting remains authoritative.

## Rationale

A confirmed access denial requires different remediation from a generic outage.

## Alternatives or migration

Leave the archive disabled until access can be provisioned safely.

## Related diagnostics

`SWDB3001` covers unclassified database failures.
