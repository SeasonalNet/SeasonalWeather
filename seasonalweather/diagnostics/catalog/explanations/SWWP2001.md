# SWWP2001 — Worker diagnostic contract is incompatible

## Meaning

The worker diagnostic schema or catalog identity does not match controller support.

## Trigger

A bounded worker envelope declares an unsupported diagnostic schema or a different catalog identity.

## Correction or recovery

Upgrade or roll back the worker and controller to compatible release contracts, then reconnect through normal SWWP registration.

## Operational effect

Bounded opaque worker code and message evidence may be retained, but worker claims cannot override local catalog policy.

## Rationale

Compatibility evidence should survive without allowing remote input to become local catalog authority.

## Alternatives or migration

During a controlled rolling update, treat mismatch as visible degraded compatibility until versions converge.

## Related diagnostics

- `SWWP1001` reports invalid or unsafe worker diagnostic input.
