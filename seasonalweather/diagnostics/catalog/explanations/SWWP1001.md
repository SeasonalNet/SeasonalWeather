# SWWP1001 — Worker diagnostic envelope was rejected

## Meaning

A simulated worker diagnostic could not be accepted as bounded, authorized, and internally consistent input.

## Trigger

Validation rejects malformed fields, unsafe text, contradictory identity, invalid transition, stale ownership, or unsupported structure.

## Correction or recovery

Correct the worker implementation and replay only a fresh envelope under the current authenticated simulated session.

## Operational effect

The untrusted diagnostic does not mutate occurrence state; the controller records only bounded rejection evidence.

## Rationale

Worker input cannot be allowed to crash the controller, poison persistence, define catalog policy, or select controller occurrence identities.

## Alternatives or migration

Use the negotiated SWWP diagnostic schema and the controller-issued occurrence relationship for resolution.

## Related diagnostics

- `SWWP2001` reports a well-formed but incompatible diagnostic contract.
