# SWDB2001 — Required PostGIS extension is unavailable or incompatible

## Meaning

The configured archive requires a PostGIS capability that the PostgreSQL extension state does not provide.

## Trigger

Database preflight confirms that the extension is missing or incompatible. A failed database connection or probe is not proof of incompatibility.

## Correction or recovery

Ask the database administrator to install or repair the required extension, then rerun preflight.

## Operational effect

The optional archive cannot qualify for the required capability. Local broadcast continues.

## Rationale

Operators need to distinguish this condition from failures owned by adjacent subsystems.

## Alternatives or migration

If the deployment does not need spatial support, use a supported non-spatial archive configuration.

## Related diagnostics

`SWDB3001` reports a database operation failure rather than a known incompatible extension state.
